# Fonts

Bundled so a self-hosted Homa never fetches fonts from a third party.

| Font | Use | Source | Licence |
| --- | --- | --- | --- |
| Satoshi (variable, roman and italic) | Body and UI | [Fontshare](https://www.fontshare.com/fonts/satoshi) by Indian Type Foundry | ITF Free Font License |
| Rajdhani (variable) | Headings | [Google Fonts](https://fonts.google.com/specimen/Rajdhani) by Indian Type Foundry | SIL Open Font License 1.1 |

Vazirmatn (Farsi) comes from the `@fontsource/vazirmatn` package (SIL Open Font License 1.1).
