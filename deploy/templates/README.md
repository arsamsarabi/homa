# One-click templates

Templates for home-server platforms. Each has a doc page in `docs/self-hosting/`:

| Platform | Files | Doc |
| --- | --- | --- |
| Unraid | `unraid/homa.xml` | [unraid.md](../../docs/self-hosting/unraid.md) |
| TrueNAS (24.10+) | `truenas/docker-compose.yml` | [truenas.md](../../docs/self-hosting/truenas.md) |
| CasaOS | `casaos/docker-compose.yml` | [casaos.md](../../docs/self-hosting/casaos.md) |
| Umbrel | `umbrel/homa/` | [umbrel.md](../../docs/self-hosting/umbrel.md) |
| YunoHost | `yunohost/` | [yunohost.md](../../docs/self-hosting/yunohost.md) |

None has been tested on the real platform yet. On a new release, update the version (and, for Umbrel and YunoHost, the digest or archive checksum) in each.
